# Support

## What this repository supports

This repository is maintained by DataNivra on a **best-effort** basis. It offers examples and
templates, not a service, and it has no response-time commitment. Issues here are the right
place for:

- a bug in an example, template or GitHub Action of this repository;
- documentation in this repository that is wrong, unclear or out of date;
- a request for a new example (we cannot promise to add it).

## What it does not support

- **Your DataNivra account, subscription, billing or a production incident.** Use the support
  channel of your DataNivra plan, or the contact form at https://www.datanivra.com/contact.
  Opening an issue here does not create a support case.
- **Security reports.** Use a private security advisory ([SECURITY.md](SECURITY.md)), never a
  public issue.
- **Questions that need your data.** Never paste real records, logs with personal data,
  credentials, connection strings or tokens into an issue. Reproduce the problem with synthetic
  data ([SYNTHETIC_DATA_POLICY.md](SYNTHETIC_DATA_POLICY.md)).

## Versions

The README lists the DataNivra versions these examples were written for. Older releases of this
repository are not maintained.
